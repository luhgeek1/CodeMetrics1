# CodeMetrics

Платформа аналитики для команд разработки: React/Vite на фронтенде, TypeScript + Node.js 24 + NestJS 12 на бэкенде, GraphQL/Apollo Server 5, Prisma ORM 7 и PostgreSQL 16.

## Запуск

Нужен Docker с Docker Compose v2. Если `backend/.env` ещё нет, создайте его из примера:

```sh
cp backend/.env.example backend/.env
docker compose up -d --build
```

Миграции и начальные роли применяются автоматически. Контейнеры продолжают работать в фоне.

| Адрес | Назначение |
| --- | --- |
| https://localhost:8443 | Фронтенд |
| https://localhost:8443/graphql | GraphQL и Apollo Sandbox |
| http://localhost:18080/health | Проверка бэкенда и соединения с PostgreSQL |

HTTPS использует локальный самоподписанный сертификат: при первом открытии браузер попросит разрешить переход. Создать аккаунт можно через **Create Account**. Порты меняются переменными `HTTP_PORT`, `HTTPS_PORT`, `API_PORT` при запуске Compose.

```sh
docker compose logs -f backend
docker compose down
```

Обычный `down` сохраняет данные в `postgres_data`. База PostgreSQL остаётся единственным хранилищем приложения, включая сессии и ограничение частоты запросов.

## Функциональность

- Регистрация, вход, выход, access/refresh JWT, ротация сессий, CSRF для обновления браузерной сессии, Argon2 и ограничение частоты запросов.
- Профиль пользователя, языки, роли, разрешения, административные блокировки и статистика регистраций.
- Проекты, репозитории, ветки и коммиты с курсорной пагинацией.
- KPI, дневная активность, часовые и недельные распределения, размеры коммитов, разработчики и рекомендации.
- Импорт из внешнего Source Code API с разбором diff, нормализацией авторов и обновлением агрегатов.

GraphQL предоставляет те же операции через типизированную схему. Текущий фронтенд продолжает использовать совместимый REST API `/api/v1`: контроллеры и GraphQL-резолверы вызывают одни и те же сервисы.

## Внешние данные

Настройте `API_URL`, `API_USERNAME`, `API_PASSWORD` и при необходимости `API_AUTH_PATH` в `backend/.env`. `API_URL` — базовый адрес API ресурсов, `API_AUTH_PATH` — путь авторизации относительно корня его сервера. После изменения настроек пересоздайте контейнер:

```sh
docker compose up -d --force-recreate backend
```

По умолчанию импорт запускается один раз после старта. `SYNC_INTERVAL_MINUTES=15` включает периодическую синхронизацию. `SYNC_ON_START=false` отключает начальную загрузку. Статус и ручной запуск доступны администратору через `syncStatus` и `syncSource` в Sandbox. Если внешний API недоступен, приложение продолжает работать с сохранёнными данными; демонстрационные данные автоматически не добавляются.
